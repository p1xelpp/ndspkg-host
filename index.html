ndspkg Repository Host

Package manager for Nintendo DSi using ftpd

About ndspkg

This repository serves as a package hub for ndspkg. It allows you to host, browse, and quickly install homebrew applications directly onto your custom-firmware enabled Nintendo DSi over Wi-Fi.

How to Connect Your DSi

  1. Ensure your Nintendo DSi is running and connected via FTP using ftpd.
  2. Make sure you have downloaded the manager client configuration tools on your PC via ndspkg.
  3. Add this repository URL to your setup config if it is not present by default:
    https://github.com/raw/refs/heads/main/index.json
  4. Run ndspkg.py on your cli: 
    python ndspkg.py
    (Tip: You can use the lsp command to query and find available titles across the index)
  5. Wait for the files to download directly to your SD card, then boot up your system!

Repository Index Format

Applications in this index are managed inside the index.json configuration layout structure:

{
  "packages": [
    {
      "name": "dsicalendar",
      "version": "1.0",
      "description": "A calendar application for the Nintendo DSi",
      "url": "https://githubusercontent.com"
    }
  ]
}
