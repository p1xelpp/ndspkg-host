# ndspkg repo

This folder is ready to be committed to GitHub as a package repository.

## Files
- `index.json` - package index used by ndspkg

## Example index format

```json
{
  "packages": [
    {
      "name": "testpkg",
      "version": "1.0",
      "description": "Example package",
      "url": "https://raw.githubusercontent.com/yourname/yourrepo/main/3d_text_over_3d.nds"
    }
  ]
}
```
